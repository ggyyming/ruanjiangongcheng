# 任务C 配置修改说明

补丁文件：`任务C配置.patch`，基于仓库 `main` 提交 `4b2b135`。

## 修改内容

| 文件 | 修改 | 原因 |
|---|---|---|
| `config/settings.py` | `INSTALLED_APPS` 增加 `"apps.loans"` | 注册借用应用（含迁移、模板、静态文件和测试） |
| `config/settings.py` | 增加 `LOGIN_URL = "admin:login"` | 本包页面使用 `@login_required`；仓库尚无业务登录页，先跳转 Django 管理后台登录 |
| `config/urls.py` | 增加 `path("loans/", include("apps.loans.urls"))` | 挂载借用、争议、通知页面 |

## 应用方式

在目标仓库根目录：

```bash
git apply --check 任务C/config/任务C配置.patch
git apply 任务C/config/任务C配置.patch
```

## 冲突处理

A/B 包可能已修改同一文件，按下面的最小合并方式手改，不要整文件覆盖：

1. `INSTALLED_APPS`：只追加 `"apps.loans"`；保留其他成员的应用列表和顺序。
2. `urls.py`：只追加 `loans/` 的 `include`；保留其他路由。本包模板使用 `{% url 'loans:...' %}`，前缀可以改。
3. `LOGIN_URL`：若 A 包已定义自有登录路由，保留 A 的设置并删除本包的临时行；本包页面会自动跳转到 A 的登录页。若没有，保留 `"admin:login"` 以保持页面可用。

如果补丁因上下文变化无法应用，可先 `git apply --reject`，再手工合并上述三处。

## 不需要修改的部分

- `pyproject.toml` / `uv.lock`：本包未新增依赖（仅使用 Django 标准能力）。
- 数据库：使用项目现有 SQLite 配置；新增 `loans.0001_initial` 迁移，随 `manage.py migrate` 执行。
- 静态文件：位于应用内 `static/loans/`，开发服务器自动发现；生产收集静态文件时随 `collectstatic` 处理。
