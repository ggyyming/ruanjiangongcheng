# A 部分测试运行记录

## 运行环境

| 项目 | 值 |
|---|---|
| 操作系统 | Windows 11 Home China 10.0.26200（x64） |
| Python | 3.13.17（python.org 官方构建，经 winget 安装） |
| uv | 0.10.9 |
| Django | 5.2.17 |
| 数据库（测试） | SQLite 内存库（Django 自动创建/销毁） |
| 运行目录 | `campus-market/` |
| 执行日期 | 2026-11-26 |

> 环境备注：本机原 venv 基于 Anaconda Python 且其标准库字节码被其他版本解释器编译过，导致测试运行出现 "unknown opcode" 崩溃；换用 uv 托管构建（python-build-standalone）后又出现间歇性段错误（该构建在 Windows 上的已知问题）。最终改用 **python.org 官方 CPython 3.13.17** 重建 venv 后，全部测试稳定通过。
