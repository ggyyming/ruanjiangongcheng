# A 部分测试用例表

> 层级说明：TC-A-01~16 与 17~27 为**服务层测试**（直接调用 services 函数）；TC-A-28~44 为**视图/表单层测试**（经 Django 测试客户端走 HTTP 路由）。
> 代码位置：`apps/accounts/tests.py`、`apps/catalog/tests.py`、`apps/accounts/tests_views.py`、`apps/catalog/tests_views.py`。
> 需求编号取自任务 A 交付文档：`CP-R-xx` 为需求，`CP-D-xx` 为细则，`A1~A5` 为本轮图片模块验收用例，M0 为共同开发约定接口。
