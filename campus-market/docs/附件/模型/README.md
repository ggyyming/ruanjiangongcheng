系统上下文图采用方框与带交互说明的箭头；不声称为数据流图。用例图采用带 «actor» 标识的参与者、椭圆用例及系统边界，关联线不表示执行先后。状态图按对象分开；圆角矩形表示状态、带 ST 编号箭头表示转换，复杂条件及角色见[转换表](../状态转换说明.md)。没有画活动图或领域类图，不以其他符号冒充这些模型。

图只表达本轮已选规则的核心路径；具体身份材料、支付服务能力、争议关闭细则、重新开放及超期批准等仍待确认。状态保持/数据确认记录见转换附件，不当作状态变化。

可用 draw.io 打开源文件编辑。`build_diagrams.py` 保存本轮模型数据，运行 `python build_diagrams.py` 可重建 draw.io 和 SVG；本机安装 Pillow 及微软雅黑字体时同时导出 PNG。若直接在 draw.io 改动，应重新导出同名文件，不再用旧脚本覆盖人工修改。当前导出已检查 XML 结构并进行 PNG 视觉查看，人工符号与业务复核待开展。
