## 3. 测试环境

三任务由不同成员在各自本地环境运行，均为 Django 5.2.17 + SQLite 内存测试库（`file:memorydb_*`，运行后自动创建 / 销毁，不触碰开发库 `db.sqlite3`）：

| 任务 | 操作系统 | Python | Django | 测试库 |
|---|---|---|---|---|
| A | Windows 11（10.0.26200） | 3.13.17 | 5.2.17 | SQLite 内存库 |
| B | Windows 11（10.0.26200） | 3.13.15 | 5.2.17 | SQLite 内存库 |
| C | Windows 10（10.0.19045） | 3.13.5 | 5.2.17 | SQLite 内存库 |

统一在 `campus-market/` 目录下执行：

```bash
uv run python manage.py test apps.accounts apps.catalog   # A
uv run python manage.py test apps.transfers apps.payments # B
uv run python manage.py test apps.loans                   # C
```
