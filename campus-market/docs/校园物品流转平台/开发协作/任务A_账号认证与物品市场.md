# [A] 账号认证与物品市场

本文可直接作为 GitHub Issue 正文。主责成员独立完成本包，最终由本对话 Codex 集成；不能把“页面做好，后台让别人写”作为完成。

## 输入与目标

先读 [共同开发约定](共同开发约定.md) 和 [总体分工](README_总体分工.md)，使用共同约定中的 AI 开工提示词。业务依据是 [需求规格说明书](../需求规格说明书.md) 的 CP-R-05～08，以及 CP-D-01～05、10、11、22、23。具体数据和状态以 [细则](../附件/01_规则与数据/业务细则确认记录.md) 和 [状态说明](../附件/01_规则与数据/状态转换说明.md) 为准。

目标：用户能注册登录、提交校内认证，负责管理员能审核；通过认证的用户能发布出售、赠送、出借物品，内容通过审核才公开。匿名用户可浏览；B/C 能直接复用本包用户、物品、资格判断和页面基础。

## 工作清单

- [ ] A0：沿用 Django User/Session，提供认证申请与 Item 初始模型、迁移、共同接口；完成公共模板和导航位置。先交依赖小 PR，不等待全部页面完成。
- [ ] 注册、登录、退出及个人主页。密码使用 Django 机制，账号登录与校内认证分开；仅用虚构姓名、学号/工号、院系/部门演示，不上传证件图片。
- [ ] 本人提交认证资料；负责管理员人工审核，记录核验情况、结论、时间、驳回原因；驳回后允许修改重提，每次保留独立提交和审核历史。
- [ ] 认证撤销记录原因：禁止新增发布和申请，下架未预留公开物品，通知相关用户；已有流转保留履约入口。撤销过程中与 B 状态协调，不能因正在预留而误下架/误取消。
- [ ] 物品字段和页面：名称、类别、描述、瑕疵、图片、流转类型、出售价格/借用押金展示、昵称、校内大致区域；联系方式和具体地点独立存储及授权展示。借用最终押金按 C 的双方约定固化。
- [ ] 发布草稿/提交、负责管理员审核、驳回原因及修改重提、违规下架通知、物主查看审核历史。审核记录关联发布版本，避免修改后沿用旧审核结论。
- [ ] 公开列表与详情，仅查询符合展示条件的物品。提供能找到出售/赠送/出借物品的浏览入口；不扩展推荐、聊天、购物车或复杂搜索功能。
- [ ] 有进行中流转禁止编辑；其余修改后待审核并隐藏。归还或撤销退回后由物主申请重上架且重新审核，丢失结清物品不能重新开放。交付前普通取消由 B 按原展示条件恢复。
- [ ] 图片仅作物品展示，使用 Django 既有上传机制并限制允许的内容、大小和访问；若引入 Pillow，由集成者协调依赖。争议私密附件不可借用公开物品图片目录直接暴露。
- [ ] 身份资料仅申请人和负责审核管理员可见；非负责管理员、其他学生直接访问详情/下载地址也拒绝。联系方式和具体地点仅预留后双方可见，拒绝时不在 HTML、表单初始值或 JSON 中泄露。
- [ ] 补全本包测试、演示初始化所需虚构数据创建方式、模块说明和交接记录。

## 页面与文件边界

主要修改 `apps/accounts/`、`apps/catalog/`、应用内模板和测试；公共模板 `templates/base.html` 与公共样式由你维护。建议 `/accounts/` 和 `/items/` 命名空间。审核可使用自建管理页面或受限 Django Admin，必须满足负责管理员的对象权限要求。

不实现预留、双确认、资金、延期、逾期限制或争议状态。不要直接改 B/C 的表。B/C 提供事件后调用 C 的通知服务；A0 阶段若通知尚未可用，明确依赖未联调，最终不能静默丢通知。

## 必须对接的接口

实现共同约定的 `is_verified`、`can_display`、`change_availability`。B 提供进行中流转/预留事实和当事人查询，C 提供通知；需要补充的查询签名在 M0 写入共同约定并由相关成员确认。不能以公开 URL 查询参数声明“我是当事人”。

## 最小验收

| 检查 | 预期 |
|---|---|
| 访客/未认证发布或申请 | 服务端拒绝，无新增业务记录；申请操作与 B 集成测试 |
| 驳回后重提 | 新审核通过前仍无参与资格，历次资料/结论保留 |
| 待审/驳回物品直接访问 | 不能作为公开商品展示，物主及负责管理员按权限查看 |
| 认证撤销时存在预留和普通公开物品 | 普通公开物品下架，已有预留不自动取消、归还入口保留 |
| 非当事人/非负责管理员访问私密字段 | 拒绝且响应内容不泄露 |
| 已通过内容审核后修改 | 重新待审，审核前不公开；进行中则拒绝修改 |
| 普通取消、归还、丢失结清 | 分别按需求处理，不统一无条件上架 |

至少覆盖 CP-SC-02，以及新增细则的认证重提、撤销、编辑重审、权限回归。运行本包测试及 `uv run python manage.py check`；在交接时给出真实测试模块和结果。
