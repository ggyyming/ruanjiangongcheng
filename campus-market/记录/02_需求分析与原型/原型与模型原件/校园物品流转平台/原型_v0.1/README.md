# 双主题可点击模拟原型 v0.1

双击打开同目录的 `index.html`，使用现代浏览器；不需要安装依赖或启动后台。

1. 选择“校园物品流转”或“课程需求审查”。
2. 选择场景，阅读初始条件和关联规则。
3. 在角色下拉框选择本步参与者，点击操作；也可用错误角色检查拒绝和状态保持。
4. 核对当前状态、步骤说明与点击记录。可下载本场景 JSON 记录并由实际走查者填写观察结论。
5. 记录需要保留时先下载；重置、切换或刷新会清空当前场景的内存进度。

## 实现与限制

- 实际实现：本地页面、场景及角色切换、预置步骤的状态展示、角色不匹配拒绝、点击记录下载。
- 仅模拟：身份和物品审核、下单、支付、退款、结算、押金、逾期、赔偿、文档上传、解析、AI 审查、教师复核和版本复审。
- 所有数据、人物、金额、日期和回执均为虚构示例；本原型不读取任意上传文件、不接收真实款项、不调用模型、不验证真实身份，不实现服务端授权。
- 原文及 AI 候选为预置文本，不构成审查效果评价样本或独立准确率证据。
- 这是按场景点击的引导原型，支持指定路径；不是可以任意组合操作的完整程序。
- 未定规则如撤销或归还后重新开放、延期跨原到期点才批准、退款失败后的处置，在相应场景中标明待确认，不擅自提供完整处理。
- 页面与模拟交互走查通过不能写成业务功能、支付接入或 AI 效果验证通过。

## 可运行检查

在本目录运行 `node check-state.cjs`。检查脚本适用于已安装 Node.js 的环境；仅验证原型脚本的预设状态和角色约束。源码 `engine.js`、`scenarios.js`、`app.js`、`styles.css` 可直接编辑。
