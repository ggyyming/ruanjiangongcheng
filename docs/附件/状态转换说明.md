# 双主题状态转换与事件说明 v0.2

依据需求稿 v0.2。业务规则的“用户已选定、业务确认待开展”状态不因进入表格而改变。CP 为校园平台，DR 为智能审查。每一编号只定义一次，可在多个场景复用。

本表既记录核心状态转换，也记录单侧确认/数据更新以及拒绝后的状态保持。单侧确认不自动改变核心业务状态；发生数据更新时明确说明。原型是预置路径，没有完整后台状态机。
