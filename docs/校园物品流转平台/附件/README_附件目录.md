# 附件目录

首选入口：[00_附件导航.html](./00_附件导航.html)。整套材料可在[实验报告离线阅读.html](./实验报告离线阅读.html)中查看；该旧入口路径保留。

| 文件夹 | 内容 | 建议检查方式 |
|---|---|---|
| 01_规则与数据 | 23项细则、规则清单、状态说明、需求追踪 | 先看规则与模型复核清单，再按编号查细则 |
| 02_模型图 | PNG图片、draw.io源文件、SVG分别放置 | 先看01_查看图片；需要编辑才打开源文件 |
| 03_场景与原型 | 11个场景的记录与可点击原型 | 先读场景，再打开原型选择校园物品流转 |
| 04_验证证据 | 原始人工反馈、历史自动检查、历史版本清单 | 按报告E编号逐份核查 |
| 05_整理与复审 | 成员说明、复审、原文快照及版本保留说明 | 查询整理过程和未验证边界 |
| 06_课程依据 | 原始课程要求及本组模板 | 核对课程要求与模板来源 |
| 07_历史版本 | 校园旧图、联合旧版原型、联合审查旧图（分别标明） | 只用于历史追溯 |
| 08_维护工具 | 生成脚本、模型摘要及路径对照 | 维护时使用，检查时通常不用打开 |

本次仅分类存储、修复链接及同步用户已填写的提交版本/日期，不改业务规则、历史证据结果或原型功能。
