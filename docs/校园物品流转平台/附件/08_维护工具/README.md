# 维护工具

日常检查请打开上级目录的[附件导航](../00_附件导航.html)，不必运行本目录工具。

- `生成离线阅读.py`：刷新整套离线阅读及附件导航，需Python。
- `生成修订模型.py`：根据现有分析数据生成六组已修订模型，需Python及Pillow；输出分别进入图片、draw.io、SVG目录。
- `修订模型清单.json`：本轮六组模型的版本摘要，用于核对导出文件。主动修改模型后，应核对源文件与导出并更新该清单。
- `附件路径映射.json`：本次分类前后的路径对照。

仓库级材料检查位于工作区 `docs/检查分主题材料.py`。生成工具不证明人工业务验证已完成。
